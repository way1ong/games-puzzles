- Оновлення після змін у грі: `npm run build:claude -- <гра>` → файл `dist/claude/<гра>.html` опублікувати на ту саму адресу (з іншої розмови — передати адресу як `url`, інакше вийде нова сторінка).
- Відмінності від гри на сайті: відступи з боків 16 px; Blocks — без перемикача вібрації; «Скопіювати результат» там, де браузер не дає копіювати, показує виділений текст; встановити гру й грати без мережі з тестової сторінки не можна (там браузер цього не дозволяє) — це запрацює на справжній адресі; у Detective кнопка «Назад» телефона на тестовій сторінці не повертає до списку справ (є кнопка зі стрілкою в самій грі). У Words словники трьох мов вкладені в саму сторінку (1,6 МБ), тож вона відкривається трохи довше.
