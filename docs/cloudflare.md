# Cloudflare: як ігри потрапляють у мережу

Ігри — статичні файли (`dist/`), які віддає Cloudflare Workers (static assets). Налаштування — `wrangler.jsonc` у корені. Збирає й викладає Workers Builds після кожного злиття в `main`, так само як сайт way1ong.eu. Кожна гра — своя адреса `/<гра>/` (Blocks — `/blocks/`, Detective — `/detective/`); корінь адреси веде на `/blocks/` (`games/public/_redirects`) — доки ігри не матимуть спільної першої сторінки. Нова гра з'являється на своїй адресі сама, з наступною викладкою: у панелі нічого міняти не треба.

## Одноразове підключення (робить Дмитро в панелі Cloudflare)

1. Cloudflare → **Workers & Pages** → **Create application** → **Import a repository** (GitHub) → репозиторій `way1ong/games-puzzles`.
2. Налаштування:
   - **Project / Worker name:** `way1ong-games` — так само, як `name` у `wrangler.jsonc` (інакше збірка падає).
   - **Production branch:** `main`.
   - **Build command:** `npm run build` (типи не перевіряє; перевірки — `npm run verify` перед кожним комітом).
   - **Deploy command:** `npx wrangler deploy` (типове значення).
   - **Root directory:** порожньо (корінь репозиторію).
3. **Save and Deploy.** Ігри з'являться на адресах виду `https://way1ong-games.<ваш-піддомен>.workers.dev/blocks/` і `…/detective/`.
4. **Надіслати Claude цю адресу.** Він вписує її в ігри (`links.game` у `games/<гра>/config.ts` — посилання в «Скопіювати результат») і на сайт (картка гри з кнопкою «Грати»).
5. Гілки, крім `main`, збираються як перегляд (Preview); адреса — у розділі Previews воркера.

Версію Node збірка бере з `.nvmrc` (та сама, що в сайту).

## Перевірити на телефоні після першої викладки

- Відкрити `/blocks/`, зіграти кілька ходів; відкрити `/detective/`, почати справу й знайти кілька предметів.
- Android (Chrome, Samsung Internet): меню гри → «Встановити гру» → іконка з'явиться на екрані.
- iPhone: «Поділитися» → «На початковий екран».
- Вимкнути інтернет і відкрити гру з іконки — має відкритися й грати (у Detective — з тими самими знайденими предметами).
- Кожна гра встановлюється окремо, зі своєю іконкою: встановити обидві — на екрані має бути два значки, і кожен відкриває свою гру.

## Домен

Поки гра живе на адресі `workers.dev`. Коли way1ong.eu буде в Cloudflare, можна дати іграм піддомен (наприклад, `games.way1ong.eu`: воркер → **Settings** → **Domains & Routes** → **Add** → **Custom domain**) — за окремим погодженням. Нова адреса — нове сховище браузера: рекорди з адреси `workers.dev` туди не перейдуть.

Перевірено локально (22.11): `npx wrangler deploy --dry-run` читає 14 файлів із `dist/`; у `wrangler dev` корінь веде на `/blocks/`, `/blocks` — на `/blocks/`, маніфест, іконки й службовий скрипт віддаються з правильними типами, а гра без мережі відкривається й грає.

Перевірено локально (23.11, з Detective): у `dist/` 23 файли (обидві гри й спільний код для них); у `wrangler dev` `/detective/` відкривається, встановлюється (Chrome не знаходить жодної перешкоди), зберігає 11 своїх файлів, без мережі відкривається й грає далі зі збереженого; сховище Blocks не зачіпає.
