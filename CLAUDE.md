# games-puzzles — правила для Claude Code

Група безкоштовних ігор-головоломок way1ong **без реклами, без стеження, без акаунтів, з роботою без інтернету**. Перша гра — головоломка з блоками (робоча назва «way1ong Blocks»); друга — детектив із пошуком предметів і доказів (робоча назва «way1ong Detective»); третя — класичне судоку («way1ong Sudoku», рішення 24.11); четверта — гра в слова («way1ong Words», рішення 24.11): слова з літер на колі заповнюють кросворд; другий режим — «Поле слів»: поле літер ділиться на сховані слова (рішення 25.11); п’ята — «Пари» («way1ong Pairs», рішення 25.11): знімати однакові пари плиток зі столу, де вони лежать шарами; шоста — «Пасьянси» («way1ong Solitaire», рішення 25.11): спершу Косинка, потім Павук і Вільні клітинки; сьома — «Малюнки за числами» («way1ong Nonograms», рішення 25.11): за числами біля рядків і стовпців зафарбувати клітинки — виходить малюнок; кожен малюнок розв’язується без вгадування; восьма — «Сапер» («way1ong Mines», рішення 26.11): відкрити всі клітинки без мін, число каже, скільки мін довкола; кожне поле проходиться без вгадування; дев’ята — «Переливанка» («way1ong Pour», рішення 27.11): переливати кольорову воду по пляшечках, доки в кожній не лишиться один колір; кожен рівень розв’язний; десята — «Пересувайки» («way1ong Slide», рішення 27.11, назва робоча): п’ятнашки (плитки по порядку чи малюнок) і «Звільни шлях» (пересувати бруски, щоб вивести свій до виходу); кожна головоломка має розв’язок; одинадцята — «Пазли» («way1ong Jigsaw», рішення 28.11, назва робоча): скласти малюнок — кімнату «Детектива» — з частинок із «вушками»: 24, 54 чи 96 частинок, пазл дня. Аудиторія — насамперед жителі Європи, дорослі й старші (рішення 22.11). Ігри — водночас приклад робіт для сайту way1ong.eu і основа для персональних версій на замовлення.

- Опис кожної гри — `docs/<гра>/SPEC.md` (`blocks`, `detective`, `sudoku`, `words`, `pairs`, `solitaire`, `nonograms`, `mines`, `pour`, `slide`, `jigsaw`).
- Рішення з датами — `docs/DECISIONS.md`. Кожне нове рішення Дмитра — туди, у тому ж коміті.
- Що зроблено й що далі — `docs/STATUS.md` (оновлювати в кінці кожного кроку).
- Чому саме ці ігри — мережевий аналіз у репозиторії сайту: `way1ong/public` → `docs/research/ad-free-games-2026-11.md`.

## Порядок роботи
- Спершу план, потім дії: знайти проблему з доказами, показати план кроків, чекати погодження. Без дозволу нічого не починати, особливо на старті сесії.
- Реальність розійшлась із планом — зупинитись і повернутись з поправкою.
- До погоджених рішень не повертатись; застереження — один раз. Нову проблему називати завжди.
- Спілкування з Дмитром українською, коротко. Код, ідентифікатори, коміти — англійською.
- Гілка сесії `ccr-*` → pull request у `main`. Зливає Дмитро, пачками.
- Перед комітом — `npm run verify` (типи, тести, збірка) має бути зелено; зміни екрана — ще й перевірка в браузері на телефоні й ПК. Комітити конкретні файли, не `git add -A`.

## Непорушні правила
1. **Без реклами, покупок у грі й стеження.** Жодних рекламних мереж, аналітики, лічильників, «життів», таймерів-тисків, монет. Гра не надсилає нічого в мережу; рекорди й налаштування — лише на пристрої.
2. **Без зовнішніх запитів.** Шрифти, звуки, зображення — з самого застосунку; без CDN. Після першого завантаження гра працює без інтернету й встановлюється на телефон.
3. **Лише оригінальні ігри.** Жанр — так, копія — ні: власні назви, правила, оформлення, набори фігур. Назви, персонажі, графіку, рівні й вигляд відомих ігор не відтворювати навіть під іншою назвою. Виняток (рішення 25.11): вигляд «Мальований» може брати безкоштовні текстури й набори з дозволом на будь-яке використання (CC0 тощо), без чужих торгових марок; ліцензію перевірити в джерелі й покласти поруч, авторів назвати в «Про гру».
4. **Логіка гри окремо від екрана.** Правила (поле, фігури, ходи, очки, кінець гри, «день») — чисті модулі TypeScript без DOM, з тестами. Випадковість — лише з зерна (seed), щоб гра була відтворюваною й «головоломка дня» однаковою для всіх.
5. **Тексти — лише в словниках** за мовою з однаковими ключами (EN, HU, UK). Додати мову = новий словник, без правки коду. Угорською — на «Ön».
6. **Зручно старшим і всім.** Фігури розрізняються не лише кольором (візерунок), великий режим, цілі дотику ≥ 44 px, гра однією рукою, звук і вібрація вимкнені за замовчуванням, повага до «зменшити рух» у системі, гра з клавіатури на ПК.
7. **Жодних чисел з пам'яті** — ні в коді, ні в текстах, ні у відповіді. Правила гри (розмір поля, очки, кількість предметів і доказів) — рішення, записані в `docs/<гра>/SPEC.md` і в конфігу гри, а не розкидані по коду.
8. **Окремий файл на кожен компонент і модуль** одразу при створенні.
9. **Підпис «Зроблено way1ong»** — скромне посилання на сайт у меню «Про гру», без банерів і закликів.
10. **Секрети** — лише в налаштуваннях Cloudflare; у репозиторії їх немає.

## Стек (змінювати лише за погодженням)
- TypeScript (strict) без UI-фреймворку, збірка Vite; тести логіки й словників — Vitest; перевірка в браузері — Playwright (у хмарній сесії вже є).
- Шрифти — системні (на пристрої гравця, без файлів і запитів); кольори інтерфейсу — `games/<гра>/styles/tokens.css`; кольори малюнків Detective — `games/detective/art/palette.ts` (рішення 23.11, правила — `.claude/rules/art.md`), малюнків плиток Pairs — `games/pairs/art/palette.ts`.
- Кожна гра — окремий застосунок, який можна встановити (PWA) і який працює без інтернету. Ігри живуть на одній адресі, тож кожна має власну особу застосунку для браузера — свою теку (у маніфесті немає `id`: браузер читає його від адреси сайту, а не від теки) — і власне сховище файлів `way1ong-<гра>-<версія>`. Збірка зупиняється, якщо дві гри мали б одну особу або назва сховища однієї починалась би як в іншої (`scripts/app-identity.ts`).
- Хостинг — Cloudflare Workers зі статичними файлами (той самий акаунт, що сайт і biznesradnik): деплой — злиття в `main`, збирає Workers Builds; вручну `wrangler deploy` не запускати. Як підключити — `docs/cloudflare.md`. Адреса ігор — `games.way1ong.eu` (рішення 23.11): домен у `wrangler.jsonc`, та сама адреса для посилань у грі — `shared/core/address.ts` (тест звіряє їх).

## Команди
- `npm run dev` — локальний перегляд (`/blocks/`, `/detective/`, `/sudoku/`, `/words/`, `/pairs/`, `/solitaire/`, `/nonograms/`, `/mines/`, `/pour/`, `/slide/`, `/jigsaw/`).
- `npm run verify` — типи, тести, збірка в `dist/`.
- `npm run preview` — переглянути зібране з `dist/`.
- `npm run audit` — після збірки: розкладка й доступність у браузері всіх ігор (розміри від 320 px до ПК, 3 мови, обидві теми, великий режим, текст 150–200 %, клавіатура; Detective проходить цілу справу й звіряє кожен малюнок предмета з його розміром і місцем); наприкінці браузер відповідає, чи кожна гра для нього — окремий застосунок зі своїм сховищем файлів. `npm run audit -- detective` — одна гра. `--axe <axe.min.js>` — ще й правила WCAG 2.2 (axe-core завантажити `npm pack axe-core` у тимчасову теку; у проєкт не додавати). `--shots <тека>` — знімки.
- `npm run check:live` — після збірки й викладки: сторінки ігор на справжній адресі (`games.way1ong.eu`) байт у байт такі, як у `dist/`, і до них нічого не дописано дорогою (Cloudflare додає до сторінок домену свій скрипт вимірювання, якщо цього не заборонити — `games/public/_headers`). Потрібна мережа до адреси ігор.
- `npm run build:claude` — кожна гра одним файлом `dist/claude/<гра>.html` для тестової сторінки; `npm run build:claude -- detective` — одна гра.
- `node scripts/make-icons.mjs <гра>` — намалювати іконки знову (після зміни кольорів у `tokens.css`).
- `npm run slide:pool` — скласти набір головоломок «Звільни шлях» (`games/slide/levels/unblock.txt`) після зміни `SLIDE.pool` чи правил; близько 10 хв; старі рядки лишаються на місці, нові йдуть у кінець.
- `npm run words:fetch` — завантажити джерела словників Words (закріплені версії) у `node_modules/.cache/words-sources`; `npm run words:build` — скласти з них списки `games/words/dict/` (після зміни правил у `scripts/words/` чи ручних правок у `scripts/words/curated/`).
