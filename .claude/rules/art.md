# Малюнки (Detective)

- Малюнки — SVG кодом: функції повертають текст. Кольори — лише з `art/palette.ts` (кімнати й предмети за часом доби, люди); у решті модулів малювання кольорів немає — стереже `art/art.test.ts`. Інтерфейс довкола малюнків бере кольори з `styles/tokens.css`.
- Розміри кімнати й меблів — у `core/rooms/<кімната>.ts`; малюнок бере всі положення звідти, і з тих самих чисел складено місця для предметів. Змінюєш меблі — зміни числа там, а не в малюнку.
- Предмет малюється довкола середини свого нижнього краю й не виходить за розмір із `core/things.ts`; місце й розмір звіряє `npm run audit` у браузері.
- Правдоподібність сцени (зауваження Дмитра 23.11): світло відповідає часу доби (лампи вдень вимкнені), нічого небезпечного (запаленої свічки немає), усе стоїть, лежить, висить або на щось спирається, погода не суперечить сама собі. Нова кімната чи предмет — пройти цей перелік на знімку вдень і вночі.
- Уночі меблі темнішають сильно, предмети для пошуку — ледь-ледь (`thingPaint`): їх має бути видно.
- Прикмета, на яку вказує доказ, мусить бути видна на портреті й мати не лише колір: шарфи різних кольорів — різний візерунок, ґудзики — різна форма; новий колір — новий візерунок.
- Назви визначень у SVG (`id`) — з префіксом малюнка (`room-day-…`, `p-<місце>-<людина>-…`): на сторінці буває кілька малюнків одночасно.
